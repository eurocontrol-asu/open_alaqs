    OpenALAQS documentation¶

    This index lists every document, by what you want to do and by reader. Installation and a quick overview are in the main README. Unknown term: see the glossary. Error message: see Troubleshooting.

    By task¶

    How to... Read
    install the plugin README, Installation
    install AUSTAL AUSTAL installation
    learn with a complete example Tutorial: Rotterdam The Hague Airport
    build a study: airport layout and sources User Guide, Define emission sources
    prepare the movements file Input formats, Movements
    prepare the meteorological file Input formats, Meteorology, or convert METAR with metar_to_alaqs_meteo.py
    use recorded flight tracks (ADS-B) Input formats, ADS-B tracks
    model an engine run-up pad User Guide, Engine test sites
    set when stationary sources emit User Guide, Activity Profiles
    generate the inventory User Guide, Calculate Emissions Inventory window
    choose the emission method and calculate User Guide, Calculate emissions
    run AUSTAL and map the concentrations Dispersion modelling with AUSTAL
    check compliance with the EU limit values Dispersion, The compliance report
    open a study made with an earlier version Upgrading
    run batch calculations without QGIS Running without the QGIS window
    fix an error message Troubleshooting
    check that the installation gives the reference results Validation guide

    Writing documentation¶

    Each topic has one page; other pages give a sentence and link to it, so a change is made in one place. Before a pull request, run python3 tools/check_doc_links.py from the repository root. To preview the documentation site with search, see README, Documentation site.
